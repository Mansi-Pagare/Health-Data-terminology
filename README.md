# Health Data Terminology

A structured learning repository for healthcare data analytics, health informatics,
interoperability, claims, clinical terminology, data quality, and data engineering.

## Learning method

Each term is studied over seven days:

- Professional definition
- Simple explanation
- Two practical examples
- Data perspective
- Related terms and distinctions
- Caveats and data-quality risks
- Practical exercise

## Rules
- One term at a time.
- One learning artifact per day.
- All examples use synthetic data only.
- Definitions and standards-related details should be verified against authoritative sources.
